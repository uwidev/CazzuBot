Aegis Workspace — CazzuBot
==========================

Plan and decision workspace for the CazzuBot project. The project's own
authority docs (see `AGENTS.md` and the index in `README.md`) remain the
source of truth for architecture and conventions; this workspace holds
implementation plans and their baselines.

 -  `INDEX.md` — the plan/decision index.
 -  `BASELINE-GOVERNANCE.md` — what a baseline is here and who owns it.
 -  `baseline/` — dated snapshots of the measured project state a plan
    depends on.
 -  `plans/` — implementation plans (one file per workstream).
